## 🧩 About

**Tekken 8 Companion** is a curated list of Tekken 8 open-source tools:

- **Overlays** — on-screen helpers, layout notes, frame data viewer, practice switcher
- **Quality-of-Life Helpers** — move catalog, costume notes, overlay notes
- **Research Notes** — combo layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Practice Switcher — reset to any position
- Show Frame Data — visualize move frame windows
- Replay Notes — record and review match runs
- Playback Speed — adjust practice playback for study (0.1x to 5x)

### Wallhack
- Move Catalog — browse moves, stances, transitions
- Custom Costume Notes — organize player cosmetics
- Hitbox Trail — improved visibility for study

### Aimbot
- Practice Mode Notes — segment study on any layout
- Side Switch Control — manually switch sides mid-match
- Input Buffer Notes — chain complex maneuvers in practice
